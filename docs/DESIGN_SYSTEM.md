# 디자인 시스템 — Starlit Warmth

기준 파일: `app/globals.css`, `app/layout.tsx`, `components/byeolharu.tsx`, `components/starlit-hero.tsx`. Emotional Minimalism, Intuitive by Design, Progress over Perfection을 유지하고 밤하늘·황혼·별빛·성장의 의미를 역할별로 분리한다. 홈 인사와 상세 화면 원화는 보존한다. 홈 메인카드는 사용자가 승인한 가로형 Stage별 아트로 교체한다.

## 색과 글꼴

| Text `--ink`                                  | `#303847`             | `#F4F1E9`             | 기본 텍스트                 |

기존 `--muted`, `--body`, `--line`, `--soft`, `--accent`, `--sage-soft`, `--gold-soft`, `--danger`는 각 사용처의 의미를 유지한다. 골드와 세이지를 선택 버튼의 배경으로 혼용하지 않는다. 골드는 배경·별 아이콘처럼 쓰고 작은 텍스트에는 충분히 진한 `--accent`를 쓴다. 텍스트 대비는 일반 글자 4.5:1, 큰 글자와 중요한 비텍스트 경계는 3:1 이상을 목표로 양쪽 테마에서 계산·화면 검증한다.

Noto Sans KR Variable을 자체 제공하고 이모지에는 시스템 폰트와 로컬 Color Emoji 대체 글꼴을 사용한다. 선택된 이모지는 글리프 색상을 바꾸지 않고 채워진 배경, 대비 경계와 체크 표시로 구분한다.

## 선택 및 테마 규칙

신규 선택형 버튼·탭·요일은 미선택일 때 중립적인 `--control-bg`, 선택 시 `--selection-bg`와 `--selection-fg`로 즉시 구별한다. 선택은 굵기·경계 또는 체크 표시로도 드러내고 `aria-pressed`(탭은 `aria-selected`), 키보드 포커스와 최소 44×44 CSS px 터치를 보장한다. 프리셋의 선택 여부는 현재 월~일 집합과 정확히 일치할 때만 참이다. 이모지와 별점은 고유 색을 유지한다. 설명 문구나 범례로 모호한 상태를 보완하지 않는다.

앱의 명시적 라이트·다크 테마가 OS 선호보다 우선한다. `.byeolharu`에 각각 명시적 `color-scheme`과 토큰을 적용하고 하위 `<dialog>` 및 네이티브 입력이 이를 상속한다. 테마 변경은 입력·선택 상태를 재생성하지 않는다. Android 브라우저의 강제 다크 모드는 별도 실기기 검증 대상이며 CSS만으로 통제된다고 가정하지 않는다.

### 브라우저별 색상 호환성

OS 테마, 브라우저의 웹페이지 강제 다크 모드, 별하루 앱 테마를 각각 식별한 뒤 표시 결과를 비교한다. 특정 브라우저의 색상 변환을 Starlit Warmth 토큰 오류로 단정하지 않으며 기존 Surface/Selection/Achievement/Growth 토큰을 유지한다. Chrome에서 정상 확인된 UI를 근거 없이 바꾸지 않는다. 네이티브 폼 컨트롤과 일반 HTML 컴포넌트의 색상 처리 차이를 함께 조사하고, 브라우저 문제에 대한 CSS 우회는 재현·원인 증거와 정상 브라우저 회귀 확인 후에만 검토한다. 실기기에서 해결을 확인하지 못하면 미해결로 기록한다. 현재 삼성 인터넷 문제는 [호환성 TODO](COMPATIBILITY_TODO.md)에 **운영 스위치 변경 후 실기기 재검증 대기**로 남겨둔다.

## 화면과 컴포넌트

- 모바일 너비부터 디자인하고 작은 화면의 기록·별점·달력·계정 패널을 먼저 확인한다. 기존 `.habit-card`, `.star`, `.tabs`, `.day-tile`, `.modal`, `.panel`, 버튼 스타일을 우선 재사용한다.
- 별점은 누르는 즉시 화면과 저장에 반영되고 같은 값을 다시 누르면 취소된다. 연속 입력 중에는 카드 순서를 잠시 고정한 뒤 완료 카드를 아래로 정렬한다. 성공 토스트 대신 별점·완료 상태·별빛을 피드백으로 사용하고 저장 실패는 별도로 알린다. `aria-pressed`, 완료 상태, 저장/오류 표시를 시각·음성으로 명확히 전달한다. 미완료에 죄책감을 주지 않는다.
- 새 습관 템플릿은 추가 모달 안의 간결한 선택 버튼이며 이름·아이콘·추천 시간대·매일 반복만 채운다. 선택만으로 저장하지 않고 나머지 항목은 사용자가 편집한다. 수정 모달에는 보이지 않는다.
- Habit Configuration은 습관의 기본 설정과 삭제만, Daily Reflection은 오늘의 별점·감정 키워드·메모·단순 체크만 다룬다. 서로의 입력을 중복 배치하거나 저장 경계를 혼합하지 않으며 과거 기록과 기존 사용자 데이터를 보존한다.
- 홈 인사 ‘오늘도, 나답게 빛나는 하루’는 보존한다. V3.3 홈 메인카드는 사용자 승인 39:17 가로형 Stage 아트를 사용해 Stage 라벨·단계명·화살표만 보여주는 별자리 상세 진입점으로 만든다. 기존 밤하늘 배경과 긴 문구·오늘의 별빛 지표·독립 버튼은 이 카드에 한해 대체한다. 이는 이전 히어로 이미지 보존 규칙보다 최신 사용자 승인 결정이며 상세 2:3 원화에는 적용되지 않는다. 다른 화면의 유용한 감성 문구는 일괄 삭제하지 않는다.
- B3.2 습관 카드는 승인된 컴팩트한 2행 구조, 5개 별점의 44×44px 터치 영역과 상태·수정 기능을 유지한다. 아직 백그라운드 푸시를 제공하지 않으므로 알림 버튼과 관련 스위치·상단 알림 테스트 메뉴는 숨기되, 저장된 알림 설정은 보존한다. 별점에 새 배경·강한 광채를 추가하지 않으며 홈의 Stage 티저, 통계, 탭, 응원 카드는 변경하지 않는다.
- B3.3 메인 마이크로 UX: 세 지표는 중앙 정렬된 동일 너비의 3열 컴팩트 패널(모바일 목표 70~90px)에 둔다. '오늘 전체 실천'은 오늘 예정된 모든 습관의 완료/대상 수, '평균 별점'은 오늘 별점 입력된 습관의 평균, '연속 실천'은 하루 이상 실천한 연속 날짜 수를 뜻한다. 평균 별점의 금색 별은 숫자 앞에 한 번만 보여준다. 새 습관 추가는 기록보다 과도하게 강조하지 않는 아웃라인 보조 버튼으로 만들되 최소 44px 터치 영역을 유지한다. 월간 별점 매트릭스의 탐색 탭 명칭과 아이콘은 '달력'으로 표시하며 데이터·산정 방식은 바꾸지 않는다.
- B3.4 메인 하단: 마지막 습관 카드 아래의 중복 안내 문장(`gentle-note`), 응원 카드(`little-note`), 동기화 홍보 푸터(`site-footer`)를 단일 짧은 마무리 영역으로 통합한다. 사용자가 승인한 감성형 다크/라이트 황혼 파형 배경과 ‘꾸준함은 완벽함보다 빛나요.’를 보존하되, 모바일 풍경 높이 약 112px·브랜드 한 줄까지 마지막 카드 이후 약 170~185px 범위로 제한한다. 오늘 완료가 있으면 ‘오늘도 한 걸음, 잘 해내고 있어요.’, 없으면 ‘작은 시작도 충분히 소중해요.’를 보여준다. 브랜드는 작은 ‘별하루’ 한 줄로 끝내고 보조 CTA·중복 푸터는 추가하지 않는다. 별점 기록 사용법 및 로컬·동기화 안내는 계정 허브의 ‘사용 안내’에서 기존 설명 모달을 열어 보존하고, 실시간 저장/동기화 상태는 계정·데이터 관리에 유지한다. 데스크톱은 빈 사이드바를 남기지 않고 최대 900px의 기록/마무리 영역으로 정돈한다. 원화·습관 카드·기록 로직은 변경하지 않는다.
- B3.6 하단 배경 통합: 기본 보기의 감성 마무리는 독립 이미지 카드가 아니라 테마의 페이지 배경(`--bg`) 위에 반투명 황혼빛을 겹친 풍경으로 표현한다. 풍경의 맨 앞 언덕은 페이지 배경색으로 자연스럽게 이어지고, 풍경 아래에는 흐린 1px 구분선을 두어 로고/‘별하루’ 사인오프와 나눈다. 승인 시안의 감성 문구·파형·라이트/다크 톤을 유지하면서, 문구 아래 빈 공간을 줄이도록 모바일 풍경을 약 96px로 압축한다. 간편보기에서는 기존과 같이 마무리 영역을 숨긴다. 습관 카드·기록/동기화/DB 로직은 변경하지 않는다.
- B3.9 최종 푸터 기준(2026-11-20 사용자 제공 라이트/다크 비교 스크린샷): 초승달·구름 이미지 대신 **두 겹의 부드러운 보랏빛 파형**을 채택한다. 다크는 짙은 네이비 배경의 보라 계열, 라이트는 아이보리 배경의 연보라·살구빛 파형을 사용한다. 동일한 SVG 2개 경로에 테마별 CSS 변수 색상을 적용하여 늘어뜨린 이미지나 손상된 WebP가 보이지 않도록 한다. 파형의 전경은 페이지 배경(`--bg`)으로 이어지고, 푸터는 독립된 직사각형 카드가 아니라 화면 배경의 일부로 보여야 한다. 기존 문구·작은 장식 별·은은한 구분선·‘별하루’ 서명 및 간결한 위아래 여백은 유지하고, 간편 보기에서는 숨긴다. 라이트/다크 320·390·430px와 데스크톱의 정상 화면, 삼성 인터넷 실기기 재검증 대상이다.
- B3.5 간편 보기: 앱 설정의 선택형 로컬 표시 설정으로 기본 OFF, 기존 기본 보기·실천 엔진·기록 저장은 유지한다. ON일 때 상단 통계는 한 줄, 습관은 56px 한 줄씩 표시한다. 미완료를 위에, 완료를 톤 다운된 하단 접힘 그룹에 넣고 완료 후 기존 700ms 정렬 지연을 존중한다. 행을 펼치면 44px 별점 입력·기록 상세·설정 수정을 제공하고 입력 후 자동으로 접는다. 완료 그룹은 기본적으로 접으며 언제든 펼쳐 취소·수정 가능하게 한다. 미완료가 모두 없어지면 작은 격려 문구를 노출한다. 하단 풍경·휴식 습관·다음 루틴은 간편보기에서 숨기되 일반 보기에서는 그대로 유지한다. 설정은 이 기기의 localStorage에만 저장하고 클라우드/백업/DB 데이터에는 섞지 않는다.
- B3.7 완료 습관 그룹 공통화: 일반보기에도 기존 두 줄 습관 카드의 레이아웃은 유지하면서 완료 항목만 화면 아래 `완료한 습관 N개` 기본 접힘 영역으로 이동한다. 간편보기와 같은 700ms 완료 이동 지연, 해당 그룹 펼치기·기록 수정·별점 취소를 지원하며 다른 시간대 탭/날짜/계정으로 전환하면 그룹이 다시 접힌다. 그룹에는 실천 완료를 비활성처럼 지나치게 어둡게 처리하지 않는다. 앱 설정 `간편 보기` 스위치는 56×44px 터치 영역과 44×26px 실제 보이는 트랙·20px 손잡이를 분리하며, 현재 다크/라이트 토큰을 사용하고 모바일 브라우저에서 시각적 과장을 방지한다. 저장·동기화·기록 스키마는 변경하지 않는다.
- 습관 추가·수정 모달의 반복 요일 버튼은 작은 모바일 화면에서도 월~일 7개를 한 줄에 표시한다. 아이콘 팔레트는 고정된 사전 정의 순서로 그리며, 선택된 아이콘을 첫 칸으로 이동시키지 않는다. 추가 아이콘 템플릿을 고르면 선택 아이콘이 포함된 확장 목록을 열고, 사전 정의 목록에 없는 기존 사용자 아이콘은 끝에 별도로 표시해 사라지지 않도록 한다. 레이아웃만 변경하고 반복요일·아이콘 저장 값은 변경하지 않는다.
- 기본 터치 대상은 44×44 CSS px 이상으로 계획하고 실제 모바일 뷰포트에서 겹침·가로 스크롤을 점검한다. 키보드 접근, `:focus-visible`, 명확한 레이블, 스크린리더 상태, 오류 피드백을 확인한다.
- 모달은 데이터 파괴·명시적 동의 등 필요한 순간에만 쓴다. 기록에 불필요한 확인 단계를 추가하지 않는다. 라이트·다크 모두에서 선택/비선택/비활성/오류를 확인한다.

UI 변경은 자동 테스트와 별도로 실제 화면에서 모바일·두 테마·키보드·스크린리더 레이블을 점검한다. 자동 검사만으로 감성/시각 완성도를 판정하지 않는다.

## V3.2 시그니처 별자리 아트 (구현된 성장 화면)

V3.2는 [시그니처 별자리 설계](CONSTELLATION_V3_2.md)를 따른다. **Emotional Minimalism은 모든 그림을 단순화하라는 뜻이 아니다.** 홈/설정/기록의 조작 UI는 단정하게 유지하되, 성장 별자리 아트는 별하루의 대표 작품이므로 풍부한 성운 레이어·골드 광채·정교한 별자리 조형과 단계별 시각적 보상을 강조한다. 단순한 별 아이콘과 기본 연결선은 최종 품질 기준에 미달한다.

Stage 1~6 승인 원화는 모두 1024×1536(2:3)이며 `object-contain`으로 표시한다. 성장 카드·점수·문구·확대 감상은 원화와 분리된 UI다. 320px 모바일 실화면·다크/라이트·모션 감소·렌더 성능을 확인한다. Stage 6 이후에는 새 공식 임계값 없이 원화 주변의 작은 장식만 연속적으로 풍성해진다.

### 사용자 승인 Stage 6 기준 (2026-11-17)

[별자리 최종 승인 아트 기준](CONSTELLATION_V3_2.md#2a-stage-6-시그니처-아트--사용자-승인-시각-기준-2026-11-17)은 **금빛 하이라이트가 은은하게 감도는 신화적 별빛 사슴**이다. 진주빛 라벤더/청보라 몸체와 샴페인 골드 뿔, 유려한 오로라 리본, 수정 무대와 회전 금빛 은하 고리를 시그니처 요소로 사용한다. 기존 순수 SVG 별/선 원형은 역사적 탐색 자료이며 최종 디자인이 아니다. Stage 1~6의 승인 원화 PNG와 WebP는 `public/assets/constellation/`에 포함되어 있고 이미지 바이트를 임의로 수정하지 않는다. 일반 앱 UI의 간결함과 대표 일러스트의 풍성함은 구분한다.
