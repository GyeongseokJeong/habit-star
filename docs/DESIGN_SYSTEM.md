# 디자인 시스템 (현행 코드 기준)

기준 파일: `app/globals.css`, `app/layout.tsx`, `components/byeolharu.tsx`, `components/starlit-hero.tsx`. 새 디자인 토큰 선언이 아니라 현재 CSS 변수와 상호작용의 기록이다.

## 색과 글꼴

| 역할                  | 라이트                | 다크                  | 사용                  |
| --------------------- | --------------------- | --------------------- | --------------------- |
| `--bg` / `--surface`  | `#f7f7f4` / `#fff`    | `#0c111b` / `#161d29` | 바탕/표면             |
| `--ink` / `--muted`   | `#303847` / `#68717c` | `#f4f1e9` / `#a9b2c1` | 주요/보조 텍스트      |
| `--sage`              | `#526f65`             | `#b6ceb9`             | 주요 상태·링크·포커스 |
| `--accent` / `--gold` | `#896b39` / `#c9a46a` | `#edbd79` / `#e5b76e` | 별점·따뜻한 강조      |
| `--danger`            | `#a4474c`             | `#f0a0a4`             | 오류·위험             |

Noto Sans KR Variable을 자체 제공하고 이모지에는 시스템 폰트와 로컬 Color Emoji 대체 글꼴을 사용한다. 색을 추가할 때는 양쪽 테마에서 텍스트/아이콘 대비를 실제로 확인하고, 색상만으로 상태를 구분하지 않는다. `--sage`는 화면의 현재 토큰이며 버튼 배경처럼 명시적 색이 필요한 곳은 코드의 해당 스타일을 기준으로 한다.

## 화면과 컴포넌트

- 모바일 너비부터 디자인하고 작은 화면의 기록·별점·달력·계정 패널을 먼저 확인한다. 기존 `.habit-card`, `.star`, `.tabs`, `.day-tile`, `.modal`, `.panel`, 버튼 스타일을 우선 재사용한다.
- 별점은 누르면 즉시 저장되고 같은 값을 다시 누르면 취소된다. `aria-pressed`, 완료 상태, 저장/오류 표시를 시각·음성으로 명확히 전달한다. 미완료에 죄책감을 주지 않는다.
- 기존 밤하늘 히어로와 따뜻한 인사·격려 문구는 브랜드 요소다. 중복 카드·배너·토스트를 줄이더라도 유용한 감성 문구를 일괄 삭제하지 않는다.
- 기본 터치 대상은 44×44 CSS px 이상으로 계획하고 실제 모바일 뷰포트에서 겹침·가로 스크롤을 점검한다. 키보드 접근, `:focus-visible`, 명확한 레이블, 스크린리더 상태, 오류 피드백을 확인한다.
- 모달은 데이터 파괴·명시적 동의 등 필요한 순간에만 쓴다. 기록에 불필요한 확인 단계를 추가하지 않는다. 라이트·다크 모두에서 선택/비선택/비활성/오류를 확인한다.

UI 변경은 자동 테스트와 별도로 실제 화면에서 모바일·두 테마·키보드·스크린리더 레이블을 점검한다. 자동 검사만으로 감성/시각 완성도를 판정하지 않는다.
