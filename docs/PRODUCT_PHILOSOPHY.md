# 별하루 제품 철학

별하루는 하루의 작은 실천을 별빛으로 기억하는 습관 기록 앱이다. 기능 추가보다 기록을 계속할 수 있는 마음과 데이터의 신뢰를 우선한다.

1. **Emotional Minimalism**: 따뜻한 문구와 별빛 정체성을 지킨다. 중복 설명과 불필요한 요소만 덜어낸다. 감성 문구를 기계적으로 삭제하지 않는다.
2. **Intuitive by Design**: 설명 없이 선택·비선택·완료·오류를 알아볼 수 있게 만든다. 안내 텍스트로 잘못 설계된 조작을 덮지 않는다.
3. **Progress over Perfection**: 완벽함보다 작은 실천과 꾸준함을 응원한다. 미완료를 벌처럼 묘사하지 않는다. 별점과 별빛은 온화한 피드백이다.
4. **Effortless Recording**: 별점·완료 기록은 최소 터치로 끝낸다. 불필요한 모달·이동·확인을 만들지 않고 저장 결과를 분명히 알린다.
5. **Data is Personal**: 습관·별점·메모·기록을 보존한다. 비회원 로컬 기록과 회원 클라우드 기록을 구분하며 이전은 명시적 동의가 있어야 한다. 삭제·초기화·이전·복구는 원본과 충돌 가능성을 먼저 검토한다.

기능 제안은 ‘기록까지 몇 번의 조작이 필요한가?’, ‘상태를 문구 없이 이해할 수 있는가?’, ‘오프라인·계정 전환에도 원본이 안전한가?’로 검토한다. 구체적 UI 판단은 [디자인 시스템](DESIGN_SYSTEM.md), 현재 구현은 [아키텍처](ARCHITECTURE.md)에 따른다.
