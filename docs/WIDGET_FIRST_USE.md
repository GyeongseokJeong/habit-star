# 위젯 최초 표시 안내 — 내부 테스트 피드백 (2026-11-28)

관련 #189, #200. 기준 main `8041685a`, Play 내부 테스트 0.1.1 (code 2). 사용자 제공 화면과 전달된 피드백: 위젯 추가 후 '앱에서 기록을 불러와 주세요'만 보이고 어떻게 불러오는지 인지하기 어렵다. 실제 참여 인원·재현 빈도는 미확인. 별도의 개인 기록/화면을 저장하거나 참가자에게 연락하지 않는다.

## 원인과 결정

- 기존 위젯 추가/설정 흐름은 표시 동의 이후 자체 표시 캐시를 읽는다. 첫 추가/만료/인증 전환 등 유효한 projection이 없으면 앱 실행 시까지 placeholder가 남는다. 앱 열기 홈 아이콘은 존재하지만 중앙 안내 자체는 클릭 불가였다.
- 유효한 projection이 없는 **동의된** 위젯에 '습관 불러오기' / '앱 열기' 2줄의 명시적 Button(최소 44dp, Plum, 초점/눌림 상태)을 표시한다. 사용자 탭 시 기존 immutable MainActivity PendingIntent를 재사용한다. 별도의 불러오기 기능이나 새로운 서버 호출이 아니다.
- 앱 초기화 또는 foreground refresh → 검증된 snapshot → 기존 publish 경로에 의해 표시가 갱신된다. 인증/오프라인/로드 실패는 빈 캐시로 안전하게 남을 수 있으며, 성공을 가정하지 않는다. 오늘 실제 예정 없음/완료 숨김으로 전부 완료/표시 동의 OFF는 기존 별도 상태로 유지한다. 정상 목록·정상 빈 상태에서는 버튼과 pending intent를 제거한다.
- 최초 설정 적용 버튼 아래 '습관이 보이지 않으면 위젯에서 앱을 열어 주세요.'를 표시. 설정 적용 직후 강제 앱 실행, 표시 동의 자동 활성화, 자동 로그인/자료 복제, 원본 기록/알림/동기화 로직 변경은 없다.
- 다음 Play 내부 테스트 업로드 후보 version 0.1.2 / code 3. 실제 Play 최고 code < 3 확인 및 별도 서명/업로드 승인 필요.
