# 별하루 — Google Play 한국어 스토어 등록 초안

기존 승인 브랜드 및 현재 구현 기능에 기반한 **검토용 자료**. Play Console에 자동 등록/공개/심사 제출하지 않는다. 앱 이름·카피·시각 자료 최종 승인과 실제 앱 화면/정책 점검 후 사용한다.

## 기본 정보

- 기본 언어: 한국어 (ko-KR)
- 앱/게임: 앱
- 카테고리 추천: Lifestyle (라이프스타일)
- 앱 이름: **별하루**
- 짧은 설명 (80자 이내):

```text
작은 실천을 기록하고 나만의 별자리를 키워요. 습관 관리, 알림, 홈 화면 위젯을 한곳에서.
```

### 상세 설명 (4,000자 이내)

```text
하루의 작은 실천이 별빛이 되는 곳, 별하루.

별하루는 매일의 습관을 기록하고, 꾸준히 쌓아 온 실천을 나만의 별자리로 만나는 습관 기록 앱입니다. 완벽한 하루보다 다시 이어가는 작은 한 걸음을 응원합니다.

나에게 맞는 습관을 만들어 보세요.
운동, 독서, 물 마시기처럼 매일 반복하고 싶은 습관을 등록하고, 원하는 요일과 시간에 맞춰 관리할 수 있어요.

간편하게 실천을 기록하세요.
아침, 낮, 저녁에 맞춰 습관을 확인하고 완료 여부와 별점, 메모를 남길 수 있어요. 간편 보기에서는 오늘의 실천을 빠르게 확인할 수 있습니다.

홈 화면에서도 습관을 이어가세요.
미니·간편 위젯으로 원하는 시간대의 습관을 확인하고 완료하거나 취소할 수 있어요. 습관 표시 여부, 완료 항목 숨김, 테마 등도 설정할 수 있습니다.

나만의 별자리를 키우세요.
작은 실천이 쌓일수록 성장하는 별자리를 감상하고, 별빛 카드로 나의 발걸음을 남겨 보세요.

지난 하루를 돌아보세요.
달력에서 지난 기록을 살펴보고, 최근의 습관을 돌아보며 나에게 맞는 루틴을 이어갈 수 있어요.

편한 방식으로 시작하세요.
회원가입 없이도 습관을 기록할 수 있고, 로그인하면 회원 기록을 동기화할 수 있습니다. 습관 시간에 맞춘 알림과 라이트·다크 테마도 지원합니다. 알림 수신은 기기 권한과 설정에 따라 달라질 수 있습니다.

작은 실천이 모여, 오늘의 나를 빛나게 합니다.
```

스크린샷 촬영은 최신 배포 후보에서 수행하고 광고용 프레임·문구를 추가하더라도 실제 UI를 변형하거나 미구현 기능을 보여주지 않는다. 회원 이메일, 실제 습관/메모, 타 앱 알림, 기기 식별 정보는 제외한다. 이미지 실제 사용 가능 여부는 소유자 확인 및 시각 검토 후 결정.

## 관점 검토

동일 모델 구조화 검토 2회(release + android, PM/BM/마케팅/사용자/운영/QA/Android/보안 + UI). 실측, 사용자 조사 및 실제 Console 확인은 아님.

| 관점 | 1차 반박 및 수정 | 2차 결정 |
| --- | --- | --- |
| PM/마케팅/사용자 | 습관 추적 기능 나열만으로 차별성 약함 → 작은 실천·별자리 성장·간편 위젯 중심, 실제 기능만 설명 | 과장/순위/성과 보장 없는 초안 채택; 카피 사용자 승인 |
| UI/QA | 이전 웹 아이콘 또는 라운드 런처 그대로 쓰면 브랜드 불일치/마스크 중복 → 승인 아트 중앙 정사각 내보내기, 기존 원화 활용, 실제 스크린샷 별도 | 출력 규격·시안 육안 검사. 실제 Play 마스크/폰 화면 미확인 |
| BM/보안/운영/Android | 심사 전 즉시 출시/미구현 수익화 홍보는 위험 → 정책과 실제 데이터 흐름 확인·승인 전 제출 보류 | 정책/실기기/계정 조건의 실제 충족은 N/E이며 출시 판정 아님 |
