# 별빛 카드 — 인스타그램 공유 진단 및 JPG 대안

## 확인된 현상 (2026-11-21)

- 별하루의 `이미지 공유` → 인스타그램과 Android 갤러리에서 **같은 PNG 공유** → 인스타그램 모두에서 **앱만 열리는 간헐적 실패**가 확인됐다.
- 카카오톡 전달, 공유 취소 후 재시도, 원본 1080×1350 PNG 다운로드는 실기기에서 통과했다.
- 인스타그램 내부 `+` → `게시물` → 저장 이미지 선택 경로(C)는 아직 결과가 제공되지 않았다.
- A와 B에서 동일한 실패가 발생하므로 별하루만의 Web Share 요청 오류 가능성은 줄었지만, 인스타그램/Android 공유 인텐트 처리와 이미지 인코딩 처리 가능성은 분리되지 않았다. 근거 없이 원인을 단정하지 않는다.

## 최소한의 사용자 대안

- 기존 **이미지 공유**와 **이미지 저장(PNG)** 기본 버튼은 변경하지 않는다. 정상 동작 중인 카카오톡도 그대로 유지한다.
- 별빛 카드 미리보기 아래의 접힌 **인스타그램에서 게시 화면이 안 열리나요?** 항목에서 직접 게시 경로와 선택적 **JPG로 저장**을 안내한다.
- JPG는 **기존 PNG로부터 브라우저가 1080×1350의 불투명 JPEG를 다시 인코딩한 비교 파일**이다. 원화 원본이나 등록된 Stage 자산은 바꾸지 않으며, JPG 저장만 요청할 때 실행한다.
- JPG 전환은 **진단용 대안**이며 Instagram 편집 화면으로의 진입을 보장하지 않는다. 인스타그램을 자동으로 실행하거나 내부 게시화면으로 이동시키는 비공식 링크를 사용하지 않는다.

## 최종 재현 비교 항목

1. A: 별하루 공유 시트 → 인스타그램
2. B: 갤러리에서 같은 PNG 공유 → 인스타그램 (A와 동일한 간헐적 실패 확인)
3. C: 인스타그램 실행 → + → 게시물 → 동일 PNG 선택 (**확인 필요**)
4. D: JPG 저장 → 인스타그램 실행 → + → 게시물 → JPG 선택 (**확인 필요**)
5. E: 갤러리의 일반 카메라 사진을 인스타그램 공유 시트로 전송 (**확인 필요**)

가능하면 피드/스토리 대상, Instagram 버전과 실행 경로를 기록한다. A/B가 같다는 사실만으로 JPG를 기본 공유로 바꾸지 않는다.

## 자동 검증

- 기존 Stage 원화 2:3 및 카드 4:5와 PNG/Web Share 회귀 보존
- JPG 다운로드 파일 시그니처 FF D8 FF, 크기 1080×1350, 실제 브라우저 이미지 디코드 성공
- 320/390px에서 기본 PNG 저장과 JPG 대안 연속 실행, Stage 6에서도 현재 Stage 유지
- 실제 Instagram 편집·업로드는 Android 실기기에서만 최종 판정
