# 별빛 카드 — 인스타그램 공유 이슈 기록 (내부 진단)

## 실기기 관찰 (2026-11-21)

- 별하루에서 Android 공유 시트 → 인스타그램, 갤러리에서 동일 PNG 공유 → 인스타그램 모두 게시 화면이 열리거나 앱 홈만 열리는 현상이 **간헐적**으로 발생했다.
- 카카오톡 이미지 공유 및 공유 취소 후 재시도는 실기기에서 통과했다.
- 양쪽 경로에서 같은 증상이 있으므로 별하루만의 Web Share 구현 문제로 단정할 수 없다. 인스타그램 수신 처리와 OS 공유 처리 중 정확한 원인은 미확정이다.
- 인스타그램 앱 내부의 `+` → 게시물 → PNG 직접 선택과 일반 카메라 사진 공유는 결과를 아직 확인하지 못했다.

## 제품 결론: 사용자 화면 단순화

- 실험용 `인스타그램에서 게시 화면이 안 열리나요?` 안내 및 `JPG로 저장` 예외 기능은 사용자 승인에 따라 **제거**한다.
- 별빛 카드 사용자 화면은 **4:5 미리보기 + PNG 저장 + 이미지 공유**만 유지한다.
- 공유 성공은 SNS 게시 완료가 아니므로 `공유 요청을 전달했어요` 상태 메시지를 표시하지 않는다. 사용자 취소도 조용히 처리한다. 실제 API 실패는 오류 메시지로 알려준다.
- JPG 이미지의 실기기 개선 효과는 검증되지 않았으며 기본 공유 형식을 변경할 근거가 없다.
- 수신 앱별 불안정성은 사용자 화면의 상시 안내가 아니라 이 문서에서 추적한다. 기존 저장·공유·원화·습관 기록은 변경하지 않는다.

## 후속 재현 필요시

- 인스타그램 앱 내부에서 저장 PNG를 직접 선택하는 경로와 일반 사진 공유를 각각 재현해 비교한다.
- 향후 외부 수신 앱 문제에 대한 명확한 재현 증거가 확보되지 않는 한 인스타그램 전용 API 우회나 딥링크를 제품에 추가하지 않는다.
