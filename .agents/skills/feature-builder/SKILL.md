# feature-builder

## 호출 조건 및 제외 조건

신규 기능·동작 확장 때 호출한다. 순수 문서·배포·시각 조정에는 제외한다.

## 참조 문서

`docs/PRODUCT_PHILOSOPHY.md`, `docs/ARCHITECTURE.md`, `docs/DEVELOPMENT_RULES.md`.

## 실행 절차

Analyze → Design → Implement → Validate → Review. 현재 기능/호출자/저장 소비자를 추적하고 완료 조건을 정한다. 기존 로직을 재사용해 최소 구현하며 변경 경로에 맞는 스킬과 회귀 테스트를 선택한다.

## 금지 사항

구현되지 않은 동작을 이미 존재한다고 가정하거나, 무관한 기능을 재작성하거나, 동의 없는 데이터 이전 금지.

## 완료 기준

요구사항·경계·완료 조건을 충족하며 관련 테스트가 통과하고 기존 동작이 유지된다.

## 실패 시 대응

실패 경로를 좁혀 재현하고 영향 범위만 수정한다. 미실행 검증은 사유를 남긴다.

## 최종 결과 보고 형식

완료 조건 / 변경 범위 / 실행한 검증 / 남은 위험.
