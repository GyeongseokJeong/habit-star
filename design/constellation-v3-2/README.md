# 별하루 V3.2 — 시그니처 별자리 아트 검토용

이 폴더는 **아트 프로토타입**이며 현재 앱에 적용된 기능이 아닙니다.

- `layout.prototype.json`: 19개 주요 별 / 21개 연결선의 고정 좌표와 단계별 공개 시점.
- `svg/stage-01.svg` ~ `svg/stage-06.svg`: 원본 좌표를 공유하는 6개 고품질 방향 시안. 장면(배경·성운·광채·주별·연결선) 분리. 텍스트 없는 아트 전용 SVG.
- Stage 1~6: 0/7/20/50/100/200점. 하루 완료 습관별 1점, 최대 3점.
- 중요한 시각 기준: 중심별과 기존 연결 구조는 단계 전환에서 **움직이거나 사라지지 않음**. 주변 UI는 미니멀하지만 별자리 시그니처는 풍성한 광채/성운/공간감을 지향.
- Stage 6 이후 250/300/350/400점 장식 임계값은 **미확정 제안**이므로 이 SVG에 고정하지 않음.
- 이것은 앱에 연결한 SVG/React 컴포넌트나 성능 최적화된 프로덕션 에셋이 아니다. 완성도 검토 후 최적화·실화면·저사양/모션 감소·접근성 테스트를 수행할 것.
- UX 및 제품의 확정 정책: [CONSTELLATION_V3_2.md](../../docs/CONSTELLATION_V3_2.md)
